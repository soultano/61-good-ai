# 61 GOOD AI

Платформа школьной жизни школы №61 (Ташкент): кружки, события, GOOD-миссии и баллы.

- `index.html`, `style.css`, `i18n.js`: лендинг (UZ/RU/EN)
- `app.html`: кликабельный демо-прототип для браузера (без сервера)
- `tg.html`: Telegram Mini App (`/tg`), открывается из бота [@goodaiuz_bot](https://t.me/goodaiuz_bot)
- `api/`: серверные функции Vercel

Каждый push в `main` автоматически выкатывается на https://61-good-ai.vercel.app.

## Как работает Mini App

- **Ученик:** имя, класс, интересы, после чего сразу попадает в ленту. Записывается на миссии и кружки, видит свои баллы, уровень и баллы класса.
- **Учитель:** ФИО и предмет, затем статус «на проверке». Админу приходит сообщение в боте с кнопками «Одобрить / Отклонить», заявки видны и в приложении. Одобренный учитель публикует миссии и кружки, видит записавшихся и подтверждает выполнение. Баллы начисляются только после подтверждения.
- **Бот** уведомляет: админа о новой заявке, учителя о решении и о новых записях, ученика о начисленных баллах.
- Каждый запрос подписан Telegram (`initData`), сервер проверяет подпись токеном бота. Права (ученик, учитель, админ) проверяются на сервере.

## API

| Файл | Что делает |
|---|---|
| `api/_lib.js` | проверка initData, хранилище Upstash Redis, Telegram API |
| `api/me.js` | текущий пользователь и его статус |
| `api/register.js` | регистрация ученика или учителя, уведомление админов |
| `api/admin.js` | заявки учителей и решение по ним (только админы) |
| `api/missions.js` | лента, создание миссий, запись, подтверждение, закрытие набора |
| `api/bot.js` | вебхук бота: `/start` и кнопки одобрения |
| `api/setup.js` | привязывает вебхук и кнопку меню бота к сайту |

Данные в Redis: `user:{id}`, `pending_teachers`, `mission:{id}`, `missions`, `joins:{id}` (ученик → joined/done), `uj:{id}`, `pts:{id}`, `cls:{класс}`.

## Настройка (Vercel → Settings → Environment Variables)

- `BOT_TOKEN`: токен от @BotFather
- `ADMIN_IDS`: Telegram ID админов через запятую
- `KV_REST_API_URL`, `KV_REST_API_TOKEN`: добавляются сами при подключении Upstash for Redis в Storage

После смены токена или домена: передеплоить и открыть `/api/setup`.

## Локальный запуск

Без `KV_REST_API_URL` хранилище работает в памяти процесса (только для разработки). Для проверки нужна подпись initData тем же `BOT_TOKEN`.
