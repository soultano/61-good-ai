# 61 GOOD AI — Telegram Mini App

Mini App: `tg.html` (открывается как `/tg`). Бэкенд: серверные функции Vercel в папке `api/`.

## Как устроено

- Ученик: роль → имя и класс → интересы → сразу попадает в приложение.
- Учитель: роль → ФИО и предмет → статус «на проверке». Админам приходит сообщение в боте с кнопками «Одобрить / Отклонить». После решения бот пишет учителю.
- Админ (ID из `ADMIN_IDS`) может также одобрять заявки в самом приложении: «🛡️ Панель администратора».
- Каждый запрос подписан Telegram (`initData`), сервер проверяет подпись токеном бота, поэтому подделать роль или чужой аккаунт нельзя.
- Один Telegram-аккаунт = одна регистрация. Отклонённый учитель может зарегистрироваться как ученик.

Файлы:
- `api/_lib.js` — проверка initData, хранилище (Upstash Redis), вызовы Telegram API
- `api/me.js` — кто я и мой статус
- `api/register.js` — регистрация ученика/учителя, уведомление админов
- `api/admin.js` — список заявок и решение (только админы)
- `api/bot.js` — вебхук бота: `/start` и кнопки одобрения
- `api/setup.js` — один раз привязывает вебхук и кнопку меню бота к сайту

## Запуск (один раз)

1. **Бот:** @BotFather → `/newbot` → получить токен.
2. **База:** Vercel → проект → Storage → Upstash (Redis) → Create → Connect to project. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` добавятся сами.
3. **Переменные:** Vercel → Settings → Environment Variables:
   - `BOT_TOKEN` — токен бота
   - `ADMIN_IDS` — Telegram ID админов через запятую (свой ID: написать @userinfobot)
4. Задеплоить проект.
5. Открыть в браузере `https://<домен>/api/setup` — должно показать имя бота и `"ok": true`.
6. В Telegram открыть бота → `/start` → «Открыть 61 GOOD AI» (или кнопка меню слева от поля ввода).

## Что пока демо

Миссии, баллы, AI-чат и панель учителя (создание миссии, подтверждение) работают как в прототипе: данные не сохраняются на сервере. Следующий шаг — хранить миссии и баллы в базе.
